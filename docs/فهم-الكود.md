# نفهم كود المنقذ الرقمي مع مرتضى

ابدأ بفهم فكرة واحدة، ثم غيّر شيئًا صغيرًا وجربه. هذه النسخة مكتوبة بأدوات الويب الأساسية.

## 1 نكتب مهمة في missions.js

كل مهمة كائن يحتوي عنوانًا وسؤالًا وخيارات وإجابة وشرحًا ونقاطًا. الأرقام في قائمة الخيارات تبدأ من صفر:

```js
const mission = {
  title: 'أعبر بأمان',
  question: 'كيف أعبر الشارع؟',
  answers: ['أركض وحدي', 'أعبر مع شخص بالغ', 'أنظر إلى الهاتف'],
  correct: 1,
  points: 100
};
```

الرقم 1 يعني الخيار الثاني لأن ترتيب القائمة هو 0 ثم 1 ثم 2. هذا مثال للتعلّم؛ كائن المهمة الكامل في البرنامج يحتوي أيضًا معرّفًا وتصنيفًا ولونًا ووصفًا وشرحًا ونصيحة وحالة الإظهار.

## 2 نفحص الاختيار بشرط

```js
const choice = 1;
const correct = choice === mission.correct;
if (correct) {
  console.log('أحسنت! هذه إجابة آمنة');
} else {
  console.log('لنتعلّم ونحاول مجددًا');
}
```

العلامة === تسأل: هل القيمتان متساويتان؟ الدالة answerMission في state.js تنفّذ هذه الفكرة وتضيف النقاط والمحاولة إلى البيانات.

## 3 نمنع تكرار النقاط

```js
if (correct && !data.completed.includes(mission.id)) {
  data.completed.push(mission.id);
  data.awards[mission.id] = mission.points;
}
```

includes تفحص هل المهمة موجودة في قائمة المكتمل، وpush يضيف معرّفها. الرمز ! يعني «ليس». الشرط يمنح النقاط إذا كانت الإجابة صحيحة والمهمة لم تُنجز من قبل.

## 4 نفهم شكل الصفحة

- index.html يضع القائمة والمحتوى والنوافذ.
- styles.css يغيّر الشكل. جرّب تغيير قيمة --green في أول الملف.
- app.js يعرض شاشة البداية أو المهمات أو الإنجازات أو لوحة وليّ الأمر.
- state.js يفصل قواعد الإجابات والحفظ عن الشكل.

## 5 كيف يعمل الهاتف

في نهاية styles.css توجد تعليمات @media. عندما تضيق الشاشة، تتغيّر الأعمدة وتنتقل القائمة إلى أسفل الهاتف. لا نحتاج تطبيق Android منفصلًا كي نعرض الموقع على الهاتف.

## 6 لماذا يوجد كود إضافي

الرمز والنسخ الاحتياطي والتثبيت والعمل دون اتصال تحتاج تفاصيل أكثر من درس الشرط والنقاط. تعلّمها تدريجيًا. افهم مثالًا صغيرًا أولًا، ثم جرّب إضافته إلى مشروعك بإشراف شخص بالغ. لا تقل إنك تفهم كل السطور إن لم تتعلّمها بعد.

## تدريبات قصيرة

1. غيّر اسم مهمة جاهزة ووصفها.
2. غيّر لون البطاقة من orange إلى blue.
3. حدّد الخيار الصحيح وانتبه إلى البداية من صفر.
4. جرّب إجابة خاطئة ثم صحيحة، واشرح ماذا تغيّر.
5. أعد حلّ المهمة وفسّر لماذا لا تتكرر النقاط.

إضافة المهمة من لوحة الأب أسهل للاستخدام اليومي؛ تحرير missions.js مفيد لتعلّم البرمجة.
